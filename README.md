# Coding Test

Python을 중심으로 알고리즘 문제를 풀고, Java와 SQL도 함께 학습하는 저장소입니다.

## 풀이 구성

| 언어 | 내용 | 경로 |
| --- | --- | --- |
| Python | 주력 언어로 알고리즘 문제 풀이 | [Python 풀이](./python/programmers) |
| Java | 알고리즘 문제 풀이 및 주요 유형 연습 | [Java 풀이](./java/src/programmers) |
| SQL | 데이터 조회·집계·조인 문제 풀이 | [SQL 풀이](./sql/programmers) |

언어별로 플랫폼과 난이도에 따라 분류하며, 각 파일 상단에 문제 번호와 공식 링크를 기록합니다.

## 실행 방법

- **Python**: 문제 파일을 직접 실행합니다.
- **Java**: 문제 클래스의 `main()`을 실행합니다.
- **SQL**: 문제에 연결된 프로그래머스 실행 환경에서 확인합니다.

Java와 Python은 로컬 실행용 코드와 제출용 풀이를 같은 파일에 관리합니다.
